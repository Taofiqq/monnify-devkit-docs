## What is Monnify DevKit?

Monnify DevKit is a command-line toolkit for developers integrating
[Monnify](https://monnify.com/) payments into an application. It brings sandbox
payment requests, webhook simulation, and delivery diagnostics into your terminal.

Use it when you are building a payment integration, investigating a webhook that
your app rejects, or checking how your handler responds to a repeated event.
These docs assume you can run terminal commands and understand basic HTTP requests.

## What can you do?

- **Start with a working handler.** Generate a small Express app that checks webhook signatures.
- **Simulate a payment event.** Send a signed payload directly to your app without completing a checkout.
- **See the delivery path.** Inspect the payload, signature result, and downstream HTTP response in your browser.
- **Repeat an event.** Replay a stored payload to exercise your app's duplicate-handling logic.
- **Call the sandbox API.** Create sandbox checkout sessions and look up transactions or bank codes.

<Note type="info" title="Sandbox only">
  DevKit v0.4.0 uses Monnify's sandbox API and accepts sandbox API keys beginning
  with `MK_TEST_`. Simulated webhooks are generated locally; they do not create
  payments or change a balance in Monnify.
</Note>

## Version and scope

These instructions target **Monnify DevKit v0.4.0**. The examples use a local
Express handler and simulated events. You need Monnify sandbox credentials for
the initial login, even though subsequent simulation runs locally.

For the complete command list, run `monnify --help`. For Monnify's API contracts
and dashboard setup, use the [official Monnify documentation](https://developers.monnify.com/).
