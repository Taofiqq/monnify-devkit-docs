## Three brief observations

1. **What worked well:** Cloud onboarding created the GitHub repository and deployed the starter successfully. The Home page showed the live address, source repository and deployment state together, making the result easy to verify.
2. **Where I encountered friction:** Creating a fresh docs repository required granting the GitHub App access to all current and future repositories. That is a broad permission scope for a small documentation project, and it became most visible during the GitHub installation step.
3. **What I would improve:** Explain that permission requirement beside the new-repository option before users leave Thally, and offer a clear, guided path for creating a compatible docs repository with selected-repository access.
